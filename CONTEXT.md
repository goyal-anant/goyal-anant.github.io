# Personal Website

Donut's personal site: static pages (bookshelf, music, research, picks) built with Jekyll.

## Language

**Preview clip**:
The ~30-second `previewUrl` audio sample for a track, sourced from the iTunes Search API and stored on the track's entry in `_data/music.yml`. Not the full song.
_Avoid_: Sample, snippet, song file

**Apple Music link**:
The `appleMusicUrl` on a track entry, pointing to that track's page on music.apple.com. Required alongside the preview clip to satisfy Apple's terms for using preview audio.
_Avoid_: Store link, listen link
